# eZWALT

[The Scaling Journey](https://ezwalt.github.io/) — notes on LLMs, world models, and AI infrastructure. Built with Astro Starlight.

## Setup

```bash
cd new_portfolio && npm install
npm run dev       # localhost:4321
npm run build     # deploy-ready output
```

Docs live under `new_portfolio/src/content/docs/`:

```text
writing/       essays and lab notes
llms/          architecture, scaling, training, Troiani
world-models/  prediction, workloads, evaluation
ai-infra/      performance, clusters, serving, platform
me/            about, CV, work, projects
```

Sidebar is defined in `new_portfolio/astro.config.mjs`.
